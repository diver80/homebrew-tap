# diver80 Homebrew Tap

Official Homebrew tap for applications and utilities by diver80.

## Installation

### PostDive (Native Email, Calendar & Contacts Suite with Flexible Local & Cloud AI)

**macOS (Universal `PostDive.app` + `postdive` CLI):**

```bash
brew install --cask diver80/tap/postdive
```

To upgrade:

```bash
brew upgrade --cask postdive
```

**Linux / CLI binary:**

```bash
brew install diver80/tap/postdive
```

Details & documentation: https://diver80.github.io/postdive/ · https://github.com/diver80/postdive

---

### OmaMac (Menu bar status panels, Jira Quick-Access & Atlassian status)

```bash
brew install --cask diver80/tap/omamac
```

OmaMac updates itself; `brew upgrade --cask omamac` works as well.

---

### Jira Quick Access

```bash
brew install --cask diver80/tap/jira-quick-access
```

To upgrade / uninstall:

```bash
brew upgrade --cask jira-quick-access
brew uninstall --cask jira-quick-access
```
